# GENESIS Documentation

## Interactive Formal Architecture Document

The full interactive React-based specification (the "sexy" visual document) lives as:

- **Local session artifact**: `React Artifact.html` / `GENESIS.html`
- **In-repo text version**: [`../GENESIS_SPEC.md`](../GENESIS_SPEC.md)

The interactive version contains:

- Live ontology table (Universe → Galaxy → Solar System → Planet → Moon → Life → Pioneer → Physics → Soul → Light → Gravity → Big Bang)
- Full `world.toml` with hardware roles (gas giants, terrestrials, observatory)
- Pioneer lifecycle stages
- Light / Gravity architecture cards
- Safety model (propose → vote → quorum, multi-sig for physics, kill hash)
- Why Solana numbers
- Next steps checklist

To view the interactive document, open the HTML file in a browser. It is self-contained (React + Tailwind bundled).

The text `GENESIS_SPEC.md` has been enriched with the complete ontology and lifecycle extracted from this document so the repo remains fully usable without the HTML.
